# Grace Community Church Management

A responsive church management dashboard built with plain HTML, CSS, and JavaScript. Open `index.html` in a modern browser; no build step or dependencies are required.

## Features

- Overview of members, attendance, giving, and upcoming events.
- Searchable member directory with member creation and removal.
- Sunday attendance tracking.
- Event creation and an upcoming events view.
- Giving records, summaries, and CSV export.
- Administrator life-event register for baptism cards and marriage certificates, including officiants, family details, witnesses, locations, notes, and automatic certificate numbering.
- Administrator dashboard totals and register tabs for baptism and marriage records.
- Multiple church workspaces with separate member, attendance, event, giving, baptism, and marriage records on the same device.
- Workspace creation and switching for different congregations.
- Browser-local persistence through local storage.

Example member, event, giving, and attendance records are included in the initial Grace Community workspace. Additional churches start with empty records. Data stays in this browser and is not sent to a server; workspaces in this demo do not have separate logins or online synchronization. Local browser storage is not a replacement for a backed-up, access-controlled church database.
